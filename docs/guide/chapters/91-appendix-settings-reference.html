Settings Reference

Every setting of the Forge engine's governed configuration, grouped by the surfaces of Settings>Configuration. Values are those of the September 2026 release; on your node, Settings>Configuration shows the value in force and the engine's own definition.

Reading this appendix

  • Default is the value before anything is committed. Where a default depends on the deployment profile the engine was installed with, the table says so.
  • Accepts is the bound the engine checks when you commit.
  • Applies: Live takes effect when committed; Restart takes effect after the engine restarts; Not active is stored for a feature that is not built yet; Host is read from the engine host's environment when the engine starts.
  • In ForgeCentral: Edit on the Configuration table, Form in Section settings, SOC tab on Settings>SOC, or Read-only.
  • A line in red corrects the label the engine shows, where this release behaves differently.

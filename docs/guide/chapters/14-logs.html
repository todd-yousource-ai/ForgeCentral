Logs

The Logs surface is the decision log: every governed decision the Forge engine made from detection, with why it fired. You filter it, follow it live, read a decision's rationale, and create an audited export.

Read the decision log

On an installed Forge node each row is one episode: the repeated firing of one rule on one subject, timed at its most recent fire, with no scope (it shows --). On a node without episodes each row is one decision. The columns are Time (UTC); Decision (the finding and the rule that fired); ATT&CK (the technique); Confidence (the engine's confidence tier); and Outcome, the posture the engine gave it. The table shows the engine's own tags (HIGH, escalate, observe-only); the filter uses the labels below:

  • Escalate: raised for a person to act on.
  • Candidate: worth an analyst's attention, not acted on automatically.
  • Observe only: recorded and watched, not raised.
Procedure
  1. Choose Logs.
  2. Narrow the list with the filter bar: Search (a finding, rule or evidence), Confidence (High, Medium, Low, Contested; an exact tier, not a minimum), Outcome, and Time range (All time, Last 24h, Last 7 days, Last 30 days).
  3. To stop the list moving while you read, choose Pause; choose Resume to follow it again. The badge reads Live, Paused, or Reconnecting after a missed refresh.
  4. Choose a row's Decision to open Why this decision fired: the finding, rule, ATT&CK technique and tactics, scope and evidence. Choose View beside the acting entity to open it in the entity drawer. Choosing elsewhere on a row opens the acting entity's drawer directly, or the rationale when the decision has no acting entity.

The log shows up to 100 rows for the current filter, newest first (fewer when the engine trims a large page). Every time range ends now, so a shorter range does not reach older rows: to find older ones, narrow the Search, Confidence or Outcome. The live refresh is a poll every two seconds, not a stream.

Export decisions

An export is an audited engine operation: the Forge engine records a receipt on its audit chain and returns the rows, which your browser saves as decision-log-receipt.json.

Procedure
  1. Set the filters. The time range ends now; its start is fixed when you last changed a filter, so change a filter just before you export if the page has been open a while.
  2. Choose Export. There is no confirmation step. The page reads Exported N decision(s); audit receipt ... recorded at version V, and the file downloads. Each export is a new request with its own receipt.

An export contains at most the 100 decisions the current filter shows, not every decision that matches. Narrowing the time range does not reach older rows (every range ends now); narrow the search, confidence or outcome instead. On an installed node the export reads decisions as well as episodes, so it can contain rows the table did not show.

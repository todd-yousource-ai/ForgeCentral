Users and Groups

The Users surface is the Forge user directory: every person, service account and AI agent the Forge engine knows about, whether you added it, an endpoint agent reported it, or your identity provider synced it. You manage the records you add, and you create groups. Identity-provider connectors, on the External IDAM tab, are covered in .

Users, origins and status

Each directory entry has a type, an origin and a status:

  • Type: Human, Service Account or AI Agent.
  • Origin: Local for a record you added in ForgeCentral; the connector's name (for example Auth0) for an account synced from your identity provider; Observed for an account an endpoint agent reported. The Origin filter offers Local and Observed, and includes synced accounts under Observed. Only local records can be changed here.
  • Status: active, suspended, revoked, disabled or compromised. You set the first three on local users; the others come from the record's source.

A status change updates the user's record in the Forge user directory and is shown wherever the user appears. Enforcement is off, so a status does not block the user anywhere yet. No action deletes a user: the record and its history remain.

Restrictions

  • Only local users have Edit, Suspend, Activate and Revoke. Change an observed or synced account at its source.
  • The user name is the record's key: it must be unique, and it cannot be changed after the user is created.
  • You can add Human users and Service Accounts; AI agents are added by observation only.

A failed Suspend, Activate or Revoke shows no error message. After changing a status, check the user's Status column.

Activate is offered on a revoked user and restores it. Do not rely on revocation being permanent; restrict who can use ForgeCentral instead ().

Find users

Procedure
  1. Choose Users>All Users.
  2. Type in Search users... to match user names, principal ids (the ID column), email addresses, organizations and group names.
  3. Narrow the list with Type, Status and Origin.
  4. Select a row to open the user in the entity drawer.

Edit a user

Procedure
  1. On a local user's row, choose Edit.
  2. Change the type, email address or organization. The user name is read-only. When identity resolution is on, a record bound to an identity-provider account keeps the provider's email address and organization; changing them is refused.
  3. Choose Save.

Suspend, activate or revoke a user

Procedure
  1. On a local user's row, choose Suspend (for an active user), Activate (for any other status) or Revoke.
  2. Confirm, for example Suspend jsmith?, with Commit.
  3. Check that the Status column shows the new status.

Create a group

Procedure
  1. Choose Users>Groups, then + Create Group.
  2. Enter a Name (required, unique) and, optionally, a Description.
  3. Choose Create. The group's card appears. A duplicate name is refused with A group with that name already exists.

On a group's card, choosing its member count searches the All Users tab for the group's name. The search is by text, so it can also list users whose name, email or other groups contain that text.

Verify

  • The user or group appears in its list with the values you entered; a local user shows origin Local.
  • Select the user to open the entity drawer and check its details.
